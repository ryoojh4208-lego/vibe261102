# PRD: 개인 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | DemoPort |
| 목적 | HRD 전문가로서의 경력, 역량, 프로젝트를 소개하는 개인 프로필 웹사이트 |
| 연락처 | ryoojh@gmail.com |
| 주 전문분야 | HRD, 교육기획, 교육진행, 조직문화 |
| 작성일 | 2026-11-03 |

## 2. 배경 및 목표

### 2.1 배경
- HRD 분야 전문성을 한곳에서 보여줄 수 있는 온라인 포트폴리오가 필요함
- 이력서/PDF만으로는 교육 프로그램의 기획 의도, 진행 사례, 성과를 충분히 전달하기 어려움

### 2.2 목표
- 방문자(채용 담당자, 협업 파트너, 교육 의뢰 기관)가 **1분 안에** 전문분야와 강점을 파악할 수 있게 한다
- 교육기획·진행 사례를 구조화된 포트폴리오로 보여준다
- 이메일을 통한 문의(채용·강의·컨설팅)로 자연스럽게 연결한다

### 2.3 성공 지표
- 방문 후 연락하기(이메일) 클릭률
- 포트폴리오 상세 페이지 조회 수
- 모바일/데스크톱 모두에서 Lighthouse 성능·접근성 점수 90점 이상

## 3. 대상 사용자

| 사용자 | 니즈 |
|---|---|
| 채용 담당자 / 헤드헌터 | 경력, 역량, 성과를 빠르게 확인 |
| 교육 의뢰 기관·기업 HR 담당자 | 강의·워크숍 주제, 진행 방식, 레퍼런스 확인 |
| 협업 파트너 (교육 컨설턴트, 퍼실리테이터) | 전문분야와 협업 가능 영역 확인 |

## 4. 주요 기능 (페이지 구성)

### 4.1 Hero (메인 첫 화면)
- 이름, 한 줄 소개 (예: "사람과 조직의 성장을 설계하는 HRD 전문가")
- 전문분야 키워드 태그: **HRD · 교육기획 · 교육진행 · 조직문화**
- CTA 버튼: "연락하기", "포트폴리오 보기"

### 4.2 About (소개)
- 자기소개 및 HRD 철학
- 프로필 사진
- 핵심 가치 / 일하는 방식

### 4.3 전문분야 (Expertise)
4개 분야를 카드 형태로 소개:

| 분야 | 소개 내용 예시 |
|---|---|
| HRD | 인재육성 체계 수립, 역량 모델링, 경력개발 프로그램 |
| 교육기획 | 요구분석(TNA), 교육과정 설계(ADDIE 등), 커리큘럼 개발, 효과성 평가 |
| 교육진행 | 강의, 워크숍 퍼실리테이션, 신입/리더십 교육 운영 |
| 조직문화 | 조직진단, 핵심가치 내재화, 소통·협업 문화 개선 프로그램 |

### 4.4 경력 (Experience)
- 타임라인 형식: 기간, 소속, 직무, 주요 성과
- 성과는 가능한 수치화 (예: 교육 만족도, 참여 인원, 운영 과정 수)

### 4.5 포트폴리오 (Projects)
- 교육 프로그램/프로젝트 카드 목록
- 각 항목: 프로그램명, 대상, 기간, 역할, 기획 의도, 진행 방식, 성과, 사진(선택)
- 분야별 필터 (HRD / 교육기획 / 교육진행 / 조직문화)

### 4.6 자격 및 교육 (Certifications & Education)
- 학력, 보유 자격증, 이수 과정

### 4.7 연락하기 (Contact)
- 이메일: **ryoojh@gmail.com** (`mailto:` 링크)
- 이메일 주소 복사 버튼
- (선택) LinkedIn 등 외부 프로필 링크

## 5. 비기능 요구사항

- **반응형**: 모바일(360px~), 태블릿, 데스크톱 대응
- **성능**: 첫 화면 로딩 2초 이내, 이미지 최적화
- **접근성**: 시맨틱 HTML, 대체 텍스트, 충분한 색 대비
- **SEO**: 메타 태그, Open Graph(링크 공유 시 미리보기)
- **다크 모드**: 시스템 설정에 따라 자동 전환 (선택)
- **유지보수**: 콘텐츠(경력, 포트폴리오)를 별도 데이터 파일로 분리하여 쉽게 수정

## 6. 디자인 방향

- 톤: 신뢰감 있고 따뜻한 느낌 (사람 중심의 HRD 이미지)
- 컬러: 차분한 메인 컬러 1개 + 포인트 컬러 1개
- 폰트: 가독성 좋은 한글 웹폰트 (예: Pretendard)
- 레이아웃: 싱글 페이지 스크롤 + 섹션 이동 네비게이션

## 7. 기술 스택 (제안)

| 구분 | 선택지 |
|---|---|
| 기본 | HTML / CSS / JavaScript (정적 사이트) |
| 확장 시 | React 또는 Next.js |
| 배포 | GitHub Pages / Vercel / Netlify |

## 8. 범위

### 포함 (MVP)
- 4장의 모든 섹션(Hero ~ Contact)으로 구성된 싱글 페이지
- 반응형 및 이메일 연락 기능

### 제외 (추후 검토)
- 블로그 / 인사이트 글 게시
- 문의 폼 (서버 연동)
- 다국어(영문) 지원
- 관리자 페이지
